## 🚀 Launch Instructions

```bash
# 🪐 Clone the repository
git clone https://github.com/ankitpoddar07/3_D-Portfolio.git
cd 3_D-Portfolio

# ⚙️ Install dependencies
npm install

# 🚀 Launch development server
npm run dev

# 🏗️ Build for production
npm run build

# 🌐 Serve production build
npm run preview
